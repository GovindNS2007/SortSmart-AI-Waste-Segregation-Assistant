What this is

A working prototype for the 1M1B AI for Sustainability internship. Type any everyday item and get an instant bin recommendation, a plain-language reason, and a disposal tip.

How answers are produced

1. First, a local knowledge base of ~60 common items is checked (fast, offline-style lookup — this is the "retrieval" step).

2. If nothing matches closely, simple keyword rules cover broad categories (plastics, e-waste, paper, etc).

3. If still unsure, the assistant asks Claude directly for a judgment call, using the same category definitions — this only runs when you (the viewer) allow it.

Responsible AI

Fairness: matching works on common aliases and casual phrasing, not just packaging labels.

Transparency: every answer shows a reason and which method produced it.

Ethics: the assistant never guesses on hazardous or medical items — it always flags them for careful handling.

Privacy: nothing you type is stored, tied to your identity, or sent anywhere except (optionally) to Claude for that one answer.
